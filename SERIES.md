# Episodes

1. Baseline: chunk, keyword retrieval, cited answers, cost per answer (this release)
2. An evaluation set: grade retrieval and answers, so every later change is measured
3. Better retrieval: embeddings and hybrid search, judged on episode 2's set
4. Caching: prompt caching and an answer cache, with the bill before and after
5. Cost tracking: per-request cost log and a budget alarm
6. Guardrails: off-topic questions, prompt injection inside documents
7. Monitoring: logging, traces, and a weekly report
8. Deploy: an HTTP API in a container
